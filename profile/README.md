## Features

- **Guided Breathing** — 5 meditation levels from beginner to advanced
- **Ambient Sounds** — 8 soundscapes including rain, ocean, and forest
- **Haptic Feedback** — Vibrations synchronized with breathing phases
- **Dark & Light Mode** — Automatic theme based on system preference
- **Completely Free** — No ads, no subscriptions, no in-app purchases
